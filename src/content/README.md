# 📁 โฟลเดอร์จัดการเนื้อหาเว็บไซต์ (Content Management Folder)

ยินดีต้อนรับสู่ศูนย์กลางการจัดการเนื้อหาของ **Ultra Creator** 
หากคุณต้องการแก้ไข เพิ่ม หรือลบข้อมูลบนเว็บไซต์ สามารถทำได้จากไฟล์ในโฟลเดอร์นี้โดยตรง โดยไม่ต้องแตะต้องโค้ดระบบหลัก:

---

### 1. 📚 จัดการบทความ (Articles)
- **ไฟล์:** `src/content/articlesData.js`
- **วิธีเพิ่มบทความ:** 
  1. เปิดไฟล์ `src/content/articlesData.js`
  2. คัดลอกแม่แบบ (Template) ที่เตรียมไว้ด้านบนสุด
  3. วางลงในรายการ `articles` แล้วเปลี่ยนหัวข้อ เนื้อหา รูปแบบวันที่ และคำค้นหา
  4. บันทึกไฟล์ เว็บไซต์จะอัปเดตบทความใหม่ขึ้นหน้าเว็บทันที

---

### 2. 🎬 จัดการคลิปวิดีโอและผลงานครีเอเตอร์ (Videos & Showcase)
- **ไฟล์:** `src/showcaseData.js`
- **วิธีเพิ่มคลิป:**
  1. นำไฟล์วิดีโอ `.mp4` ไปวางในโฟลเดอร์ `public/videos/creators/` หรือ `public/videos/testimonials/`
  2. นำภาพหน้าปกคลิป `.jpg` ไปวางใน `public/images/posters/`
  3. เพิ่มข้อมูลชื่อคลิป ยอดวิว และพาร์ทเนอร์ใน `src/showcaseData.js`

---

### 3. 🏷️ จัดการโลโก้แบรนด์พาร์ทเนอร์ (Brand Logos)
- **ไฟล์:** `src/brandLogos.js`
- **วิธีเพิ่มแบรนด์:**
  1. นำไฟล์ภาพโลโก้แบรนด์ (พื้นหลังโปร่งใส หรือไอคอน) ไปวางใน `public/brands/`
  2. เพิ่มชื่อแบรนด์และลิงก์รูปภาพใน `src/brandLogos.js`
